# TonyPlotPy

**语言：中文（默认） | [English](README.en.md)** · 版本 v0.4.2 · [MIT 许可](LICENSE)

Atlas ASCII `.str` 云图与 `.log` 曲线桌面软件。STR 页签基于 `plot_switching_str_cloud_maps_on.py`，保留网格读取、字段映射校验、镜像、结构叠加、TonyPlot 色图以及三种渲染方式。

## 运行

两个页签的“保存配置”可将数据文件顺序、所选字段/曲线、绘图参数、当前缩放范围、文字/曲线/色棒/箭头编辑及材料图例位置保存为 TonyPlotPy `.set` 文件；“导入配置”会在后台读取原始数据并恢复当前页签绘图。数据文件路径尽量相对于 `.set` 保存，移动时请保持相对目录关系。该文件为 JSON 格式，不含原始仿真数据，不兼容 TonyPlot 原生 `.set/.setx`；复现需要原数据、字体和兼容的软件版本。图片元素的现有双击编辑也可通过右键菜单“编辑此元素…”打开；缩放/平移工具开启时优先保留工具操作。

```powershell
py -m pip install -r requirements.txt
py tonyplotpy.py
```

两个页签分别管理 STR 和 LOG，各有独立的文件列表、参数、预览及导出按钮。读取和绘图在后台运行，期间窗口仍可操作。完成后可用 Matplotlib 工具栏缩放/平移，再导出 PNG、PDF 或 SVG。

STR 页签：选择含 `.str` 的目录，或添加多个文件。调整物理量、显示范围、镜像、色标、渲染方式和图的排列后，点击“画图 / 更新预览”。空色标边界代表自动计算；对数色标下，电流下限为 0 或留空时自动选取正值。

子图标题默认仅显示时间或文件标签；物理量名称保留在色棒上。勾选“显示物理量标题”可在子图标题中同时显示物理量名称。

电子、空穴、总电流密度中同时选择两种或以上时，共用一个电流密度色棒，并采用全局电流色图、标度、范围和等值带数；自动范围覆盖所选电流量。此时这些电流量的单独显示设置由全局设置替代。温度及其他物理量仍使用各自的色棒。

双击色棒、色棒标签或刻度可编辑色棒的长度、宽度、水平/垂直偏移（英寸），以及标签文字、标签与刻度字号、字体、颜色和边框线宽。勾选“将尺寸和样式应用到全部色棒”可统一所有色棒的大小，同时保留各自的标签文字。支持预览、取消恢复及确认保存；设置在重新绘图和导出时保留。

“子图轴标签…”可按行列位置、文件和物理量逐个控制 X/Y 轴名称，也可一键全部显示、仅显示外侧或全部隐藏。刻度数字仍保留；隐藏轴名称后，组合图会自动重新计算行列间距。点击“应用”会更新预览，导出使用相同布局。

LOG 页签：选择含 Atlas SSF 数据 `.log` 的目录，或添加多个数据日志。选择横轴和一条或多条纵轴曲线；“叠加曲线”将所有曲线放在一张图，“每信号子图”将多个子图放在一张图，“每曲线单独图片”可切换预览并批量导出多张图片（文件名附带曲线名称）。可调整线性/log 坐标、范围、线宽和网格。时间横轴默认以 µs 显示。运行控制台日志虽也以 `.log` 结尾，但不含 SSF 曲线数据，软件会跳过。

在 LOG 的“叠加曲线”模式下可启用“双 Y 轴”，并从已选纵轴曲线中指定右轴曲线。左轴使用常规纵轴标度和范围，右轴可单独设置 linear/log 标度及上下限；两侧曲线共用横轴和图例。

LOG 曲线默认采用白底、细坐标轴、向内刻度和可编辑 SVG/PDF 文字。两个页签都支持在预览图中双击：双击横纵轴标题或图标题可编辑文字、字号、颜色和字体；双击坐标轴、刻度或轴线可编辑轴范围、标度、刻度字号、刻度字体、刻度颜色以及横纵轴线颜色；双击图的空白处可按宽高比例、毫米或像素修改图片尺寸；默认按比例设置，10:20 对应 80×160 mm（长边默认 160 mm，可调整），器件坐标仍为 µm。双击 LOG 曲线可修改颜色、线宽、线型、数据点形状与大小，以及图例名称、字号、字体、标题和图标题。字体列表提供本机已安装的常见论文字体。预览工具栏的“添加箭头”可在同一子图中依次点击起点与终点，再设置标注文字、字体、字号、颜色和箭头线宽。双击箭头文字可修改或删除标注。编辑弹窗可先点“预览”查看效果，点“取消”恢复原图，点“确定并关闭”才保存；修改会保留到再次生成预览和导出。

导出分辨率默认 300 DPI，可在左侧“输出”区域修改。界面使用蓝色主按钮与选中态、浅蓝色背景及卡片分组；图标以蓝色为主，并有红色点缀。窗口使用 `imgs/tonyplotpy.ico` 图标；`py -m src.make_icon` 可重新生成图标（需要 Pillow）。
两个页签顶部都有“设置”按钮，可切换中文或英文、蓝色/红色/青绿/紫色主题，并调整界面字号、默认导出 DPI 和窗口尺寸。中文为默认语言；语言切换立即生效。设置保存在软件目录的 `settings.json`，下次启动自动恢复；切换主题时窗口图标也会同步改变。当前版本显示在页签底部和设置窗口。
组合图按物理量共用色条，减少重复元素；导出对话框默认打开当前页签已选择的数据目录；未选择目录时使用首个数据文件所在目录。图片可保存为 PNG、PDF 或 SVG。
“自由网格列数”表示每行放几个子图。修改该值会自动将排列切换为“自由网格”；点击“画图 / 更新预览”后生效。

## 文件结构

- `tonyplotpy.py`：Python 启动入口；`start.bat` 调用此入口
- `src/app.py`：界面、参数收集和后台任务
- `src/plotting/atlas_engine.py`：原脚本的 Atlas STR 解析与基础绘图函数
- `src/plotting/renderer.py`：组合图生成，不依赖 Tkinter
- `src/plotting/log_reader.py`：Atlas SSF LOG 字段与曲线读取
- `src/plotting/log_renderer.py`：LOG 曲线绘制
- `src/figure_editor.py`、`src/plotting/figure_edits.py`：预览图双击编辑和设置复用
- `src/plotting/font_presets.py`：常见论文字体预置与本机可用性筛选
- `src/make_icon.py`：简洁图标生成脚本
- `src/ui_settings.py`：主题、字号及窗口设置的读取与保存
- `src/i18n.py`：中文与英文界面文字
- `src/tooltips.py`、`src/control_hints.py`：悬停提示及参数说明
- `imgs/tonyplotpy.ico`、`imgs/tonyplotpy.png`、`imgs/tonyplotpy_small.png`：窗口图标和界面图标

鼠标在左侧列表内时，滚轮滚动对应列表；在其他设置区域时，滚轮滚动整块参数面板。
目录输入框、文件和曲线列表、参数输入框、下拉框、复选框、主要按钮及编辑弹窗提供悬停提示；文件提示显示完整路径，目录提示显示路径是否存在。

## 其他 STR 字段

在“视图与组合”中勾选“仅显示材料（不绘制云图）”，可按 STR `r` 记录中的材料编号填色：相同材料使用相同颜色，不显示物理场色棒，使用材料图例。“显示三角网格”可独立控制原始网格线，在材料图和云图中均可启用；“显示坐标网格”仍用于坐标参考线。

材料图也支持“显示结构与结线”：PN 结由已保存净掺杂的零等值线确定，电极由 STR 中的名称和区域关系识别；会包含结构顶部的电极范围。“显示结构标注（材料图）”控制电极名称、N/P 类型和 PN 结文字，可单独关闭。未保存净掺杂时不推断 PN 结，当前显示范围外的电极不标注。

对具有 gate/emitter/collector 接触的平面 IGBT，结构标注结合半导体区域、深度和掺杂分布推断 N 漂移区、P-well、N++、N 缓冲层和 P+ 集电极；发射极箭头指向浅表重掺杂 P 型接触区。此分类属于显示层的拓扑推断，并非 STR 自带区域名称，复杂或不同拓扑需核对。缓冲层和集电极只在深度显示范围覆盖对应区域时标注。

结构标注使用箭头且不带底色。材料图例默认位于右下角；双击图例可修改材料名称、材料填色、文字颜色、字体、字号、加粗、标题、列数、位置及背景边框，支持预览、取消、保存与撤销。双击修改图片尺寸时，预览会居中适配显示区域，导出保留设置的实际尺寸；比例值不会再当作微米长度。

已登记总掺杂、施主/受主及电离浓度、电势、电场幅值与分量、电子/空穴浓度、准费米能级、速度、迁移率及分量、焦耳热/复合热/总热功率密度、热导率、比热容、复合率和电离系数等字段。列表仅显示所选文件共同保存的已知字段，色棒附带对应单位；编号未确认的扩展字段和区域编号等元数据仍隐藏。名称与单位表位于 `src/plotting/field_catalog.py`，经 TonyPlot 5.0.22.R 的物理量目录核对。

STR 云图和动态云图均可选择「净掺杂浓度」和「绝对净掺杂浓度」。净掺杂保留 N/P 符号，默认使用对称对数色标。绝对净掺杂使用幅值，默认使用对数色标，下限为 1e12 cm⁻³，上限按当前视野内的最大幅值向上取整到十进制数量级。双击任一字段可独立修改色标范围、标度和对数阈值。`tonyplot_user_smooth` 是近似色表，逐色复现需要匹配参考 TonyPlot 的色表、显示模式和范围。

云图使用全部材料区域的三角网格和 STR 节点数值，包括电极、栅极和发射极区域；结构叠加只绘制区域边界，不再用固定材料颜色遮盖物理场。自动色标范围也包含这些区域。

软件读取 ASCII `.str` 的 `s` 记录，只列出已明确命名且在所有已选文件中存在的节点字段。电流和温度保留常用复选框；其余已命名字段可按 Ctrl/Shift 多选并生成组合图。双击列表字段或常用物理量复选框，可单独设置该字段的色图、线性/log 标度、上下限和等值带数。留空则使用全局设置或当前视野的自动色标。未命名的 Atlas 编号仍保留在解析器中，但不出现在界面列表中。

电流密度的“幅值”是 X/Y 分量的合成大小 `|J| = √(Jx² + Jy²)`；带 X、Y 的字段分别是方向分量，不是额外的总量。界面按净掺杂、传导电流、电子电流、空穴电流、总电流的顺序显示，名称明确区分幅值与分量。

当前解析器按原脚本的 Atlas 5.30 字段编号读取，并核验电流幅值与分量；适用于具有相同字段的 ASCII `.str`。二进制 `.str` 不支持。

预览工具栏的“撤销”（Ctrl+Z）可恢复已确认的文字、曲线、坐标轴、色棒、图片尺寸和箭头编辑，以及 STR 子图轴标签与字段显示设置。STR/LOG 分别保留最多 50 步；关闭软件后清空。
